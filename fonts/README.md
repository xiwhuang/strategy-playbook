# Bundled font

`xkcd-script.woff2` / `xkcd-script.woff` — **xkcd Script**, derived from the
handwriting of Randall Munroe, the author of [xkcd](https://xkcd.com).

- Source: <https://github.com/ipython/xkcd-font> (`xkcd-script/font/`)
- Licence: Creative Commons Attribution-NonCommercial 3.0 Unported (see `LICENSE`)

The `.woff2` was built from the repository's `xkcd-script.ttf` with `fontTools`;
the font outlines themselves are unmodified.

Because the licence is **NonCommercial**, this site must stay non-commercial, and
the attribution in the page footer must not be removed.
